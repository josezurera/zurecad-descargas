# zureCAD: descargas

Instalador de **zureCAD**, el editor de planos DXF de [BIM Ingenieros](https://bimingenieros.com/zurecad/), con
módulos de Estructuras, Instalaciones y Asistente de IA.

## Descargar

**[Descargar la última versión (zureCAD.msi)](https://github.com/josezurera/zurecad-descargas/releases/latest/download/zureCAD.msi)**

Todas las versiones: [Releases](https://github.com/josezurera/zurecad-descargas/releases).

## Instalar

1. Abre el archivo `zureCAD.msi` que has descargado (normalmente está en la carpeta **Descargas**).
2. Windows puede mostrar el aviso azul **«Windows protegió su PC»**, porque el instalador todavía no lleva firma
   digital. Pulsa **Más información** y luego **Ejecutar de todas formas**.
3. Sigue el instalador. Se instala solo para tu usuario (no hace falta ser administrador) y crea accesos en el menú
   Inicio y en el escritorio.

## Empezar

- El **editor es gratuito**.
- Para **Estructuras, Instalaciones y el Asistente de IA**: en zureCAD, **Utilidades › Cuenta y licencia**, escribe
  tu email y entra con el código que te llega por correo (mira también en correo no deseado). Tienes **30 días de
  prueba** de los tres módulos.
- **Beta testers** invitados: al entrar con el email con el que hiciste la solicitud, tienes los tres módulos un año.

## Requisitos

- Windows 11.
- Para abrir **DWG**: el ODA File Converter, gratuito, de la Open Design Alliance.
- Para el enlace con **TeKton3D**: TeKton3D instalado, con su licencia.
